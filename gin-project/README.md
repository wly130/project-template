### 运行项目

**在项目根目录下执行**

```
go run main.go
```

### 目录/文件

| 目录/文件        | 作用             |
| ---------------- | ---------------- |
| bin              | 启动文件         |
| config           | 配置目录         |
| config/anth.bo   | Token鉴权        |
| config/cors.go   | 跨域配置         |
| config/env.go    | 环境变量配置     |
| config/global.go | 全局变量         |
| config/mysql.go  | mysql数据库配置  |
| controller       | 控制层           |
| repo             | 数据层           |
| models           | 数据表目录       |
| service          | 服务层           |
| router/router.go | 全局路由配置     |
| validators       | 验证器目录       |
| .env             | 项目配置文件     |
| main.go          | 项目入口文件     |
| go.mod           | 项目配置文件     |
| go.sum           | 项目依赖模块配置 |
